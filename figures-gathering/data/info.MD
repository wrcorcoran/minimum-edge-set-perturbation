# Info.MD
## What experiment was conducted to gather this data?
The following:
```
After building a subgraph for each class, what happens if we turn a connected component with a certain density, in that subgraph, into a clique?
```

For more info, please see Winter 2024, Week 8 in the ResearchLog.md file located in the 2324_TeamSingh_ERSP repo.

The experiment used the parameter set to "c = 0.05."

Further experiments should be done using this question:

```
After building a subgraph for each class, what happens if we increase the density of a connected component, in that subgraph, by some constant c ?
```

Again, visit the same location for more info.
